# Integration samples

Demo patient portal of a fictional laboratory (**MockLab**), used as a base for showing how to integrate LabTest Checker. The same portal is available in two technologies, pick the one you prefer to read:

- [`mocklab-portal-php`](mocklab-portal-php) - PHP
- [`mocklab-portal-node`](mocklab-portal-node) - Node.js / TypeScript

Each folder is self-contained and has its own README with run instructions (Docker and without Docker).
